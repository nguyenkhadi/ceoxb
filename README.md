**# CEO XB Website Prototype

This is a web-first prototype for CEO XB, an invite-only CEO accountability and messaging platform.

## Features included

- Landing page
- Application form for CEOs
- Login page
- CEO demo dashboard
- Admin demo dashboard
- Admin accept/decline applications
- CEO profiles and accountability group overview
- Direct messaging demo
- Monthly KPI check-ins
- Coffee chat requests
- Events/conferences page
- Educational resources page
- Subscription/free trial pricing page
- LocalStorage demo database
- Responsive mobile-friendly layout

## How to run

Option 1: open `index.html` directly in your browser.

Option 2: run a local server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

This is a frontend prototype. It uses localStorage, so it does not have real backend security yet.**
